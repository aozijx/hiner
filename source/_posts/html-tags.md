abbr 标签用于展示缩写。
<abbr title="etcetera">etc.</abbr>
```html
<abbr title="etcetera">etc.</abbr>
```

a 标签的锚点可以用 name 属性表示，用法与 id 类似。
<a name="label">锚（显示在页面上的文本）</a>
```html
<a name="label">锚（显示在页面上的文本）</a>
```

img 元素中的 `usemap` 属性引用 map 元素的 `id` 或 `name` 属性，具体取决于浏览器实现。
