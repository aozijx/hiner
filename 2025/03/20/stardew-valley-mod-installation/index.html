星露谷 Mod 安装指南

2025-03-20T07:05:04.000Z2026-11-26T10:11:37.389Z

¶一、安装 SMAPI（Mod 加载器）

¶下载 SMAPI

  • PC:
    引用站外链接
    SMAPI
    GitHub，选择 SMAPI 4.1.10 installer.zip 下载
    引用站外链接
    SMAPI
    Nexus，需要 Nexus 账号
  • Android
    引用站外链接
    SMAPI
    SMAPI For Android

¶解压文件

将压缩包解压到当前文件夹，避免权限问题，建议路径：D:\StardewValley\SMAPI。

¶运行安装脚本

  1. 打开解压后的文件夹，双击运行 install on Windows.bat
  2. 命令行界面提示：
    • 输入 1 并回车（选择默认游戏路径）。
    • 再次输入 1 确认安装。
  3. 安装完成后会显示 SMAPI installed successfully!，并自动复制 SMAPI 启动路径（如 “D:\Steam\steamapps\common\Stardew Valley\StardewModdingAPI.exe” %command%）。

¶二、配置 Steam 启动项

  1. 打开 Steam，右键点击游戏库中的《星露谷物语》→ 属性 → 通用 → 启动选项。
  2. 将上述命令行输出的路径或 SMAPI 路径粘贴到输入框中（加上 %command% 命令），然后保存设置。

¶三、注册 Nexus Mods 账号

  1. 访问
    引用站外链接
    Nexus Mods官网
    Nexus Mods
  2. 点击右上角 Register，填写邮箱、用户名、密码完成注册。
  3. 登录后，在 Site Preferences → Content Blocking 中关闭成人内容过滤（避免部分 Mod 被隐藏）。

¶四、下载并安装 Mod

¶普通 Mod

  1. 下载 Mod
    以热门的 “自动化” Mod（Automate） 为例：
    引用站外链接
    Automate下载页
    Nexus Mods
    • 点击 Files → Manual Download 下载文件（通常为 .zip 格式）。
  2. 安装 Mod
  • 解压下载的 Mod 文件，将解压后的整个文件夹复制到游戏目录下的 /Stardew Valley/Mods 中（在 Steam 中点击“管理”→“浏览本地文件”）。

示例路径：D:\Steam\steamapps\common\Stardew Valley\Mods
如果 Mods 文件夹不存在，手动创建。

检查依赖项
  • 大部分 Mod 需要额外依赖库
  • 安装方式同上，确保依赖库位于 Mods 文件夹内。

¶美化 Mod

分为 xnb 和 png 两种格式

  • xnb
    解压后复制 Mod 文件夹中 xnb 后缀的文件，打开星露谷 /Stardew Valley/Content/Portraits 文件夹，粘贴并替换，恢复原样只需检查游戏资源完整性即可
  • png

根据前置 Mod 不同，选择不同方法

  • Portraiture
    将 Mod 中包含 PNG 图片的文件夹复制到 /Mods/Portraiture/Portraits 中即可，游戏中按 P 切换，O 为锁定肖像
  • PNG Retex Helper
    将 Mod 中的 PNG 文件夹复制到 /Mods/PNG Retex Helper/assets 中并替换即可
    实测 Portraiture P 键可替换 PNG Retex Helper 肖像
  • Fashion Sense
    将服装等 Mod 解压到游戏的 Mods 文件夹中。
    在皮埃尔商店购买 Hand Mirror。使用 Hand Mirror 即可更改 Fashion Sense 的配饰、发型、帽子、衬衫、袖子、裤子或鞋子。自定义服装也可以通过此工具保存和加载。

¶五、验证 Mod 是否生效

  1. 通过 Steam 启动游戏，会自动运行 SMAPI。
  2. 游戏启动时，命令行窗口会显示加载的 Mod 列表。
    • 白色：Loaded 表示成功。
    • 红色：Failed 表示失败。
    • 紫色：Mod 需要更新（不强制）。

¶六、常见问题

  • Mod 未加载

    • 检查 Mod 文件夹层级：正确路径应为 Mods/Mod 名称/模组文件，而非嵌套多层。
    • 确保所有依赖项（前置 Mod）已安装。

  • Mod 过期

    • 定期在 Nexus Mods 检查更新，关注 Mod 页面的 Posts 板块获取兼容性通知。

  • Mod 兼容

    • 检查 Mod 是否兼容 1.6 版本，或删除冲突的 Mod。

¶七、推荐工具

Mod 管理工具：可自动检测缺失依赖和 Mod 更新。

按照以上步骤操作，即可畅玩星露谷物语的 Mod 内容！遇到问题可查阅 SMAPI 官方文档或社区论坛。

小技巧
  • 可以在已游玩存档的任何时期添加 Mod。
  • 遇到“这个角色属于另一位玩家”问题，找到存档，记事本打开，快捷键 Ctrl + F 寻找 <farmhand> ，找到角色名称后向后寻找 <userID>xxx</userID> ，意思是只有指定 ID 的玩家可以加入游戏，改成 <userID /> 。
  • 主机位置 <player>
  • 从机位置 <farmhand>
  • 房屋代码 <farmhouse>
  • 房屋等级 <houseUpgradeLevel>
  • 记录献祭及各种邮件内容 <mailReceived>
  • 记录看过的事件等内容 <eventsSeen>
  • 记录玩家 ID 识别哪只动物是哪个玩家买的 <UniqueMultiplayerID>
